Rotate Master Vault Key (KEK)

Rotating the KEK generates a new Key Encryption Key version. All Group DEKs will be decrypted with the old KEK, re-wrapped with the new KEK, and their version fields updated. Actual profile connection credentials are never re-encrypted, ensuring instantaneous completion.

Core Frameworks & Tools

The FilePilot Enterprise Server provisioning engine is constructed using highly efficient web servers, secure relational layers, cryptographic envelope generators, and modern CSS guidelines. We thank all the contributors of the following integrated systems:

Node.js & Express

Handles fast server execution, secure REST routing, session token validation, and multi-tenant profiles deployment.

Sequelize ORM & SQLite

Manages local relational mappings, audit trails tracking, user key generation, and settings persistency.

JWT Web Tokens

Secures administrator login validations and generates remote client sync handshake keys.

TailwindCSS

Powers the modern, responsive administration console dashboard layout, sidebars, and overlays.

Chart.js

Renders dynamic system metrics, backup progress lines, and server health analytics logs on the dashboard.

Crypto Envelope API

Enables secure Key Encryption Key (KEK) rotations, AES-256 data envelope encryption, and local secrets integrity checks.

Thank you to the developers and maintainers of the open-source libraries that make enterprise computing safe and reliable!
